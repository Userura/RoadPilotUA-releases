## Поточна версія

# RoadPilotUA 0.1.6

Назви вулиць і явні номери будинків з OSM по Україні включені безпосередньо до APK. Після локальної перевірки й розпакування пакет працює без інтернету та без завантаження області. Національне охоплення включає Крим і всі 27 адміністративних територій. Відбору за розміром населеного пункту немає.

Витяг OpenStreetMap станом на **25.10.2026, 21:21:21 UTC**: **1 700 067 адресних записів**, **415 857 іменованих дорожніх відрізків**, **2 100 318 дорожніх відрізків загалом** та **36 045 позначок населених пунктів і частин міст**. Це записи об'єктів OSM, а не кількість унікальних офіційних вулиць або будинків. Один некоректний геооб'єкт пропущено під час обробки.

Адресний шар — окремий PMTiles з векторними даними, який читається тайлами видимої ділянки. Він додається до всіх режимів карти, має локальні шрифти, денні / нічні кольори та пріоритет української назви вулиці. Підписи провайдера замінені одним набором адрес; позначення трас та 3D-будівлі зберігаються. У базовому режимі додано лінії доріг. Масштаб можна збільшувати до z19; вулиці підписуються з z14, будинки — з z16.

Для ділянок без об'єктів збережені явні порожні тайли, щоб не провокувати помилки відсутніх даних або підстановку старого масштабу. На близьких масштабах грубі регіональні дороги z11–13 замінюються точними лініями нового шару; докладні регіони зберігають власну геометрію.

Детальні області з геометрією будівель завантажуються окремо. Адресний пакет не містить загальноукраїнського графа маршрутизації. GPS, голос, тривоги, камери, ліміти маршрутів і збережені області не замінюються.

Джерело — OpenStreetMap через Geofabrik. Точна дата, кількість об'єктів, розмір, SHA-256 і зразки по областях записані в `app/src/main/assets/ukraine-addresses-notice.json`. Неповнота OSM залишається: відсутні реальні адреси не вигадуються, інтерполяція номерів не використовується. При щільній забудові колізії підписів усуваються рендерером; для додаткових номерів слід наблизити карту.

Версія `0.1.6`, versionCode `18`. Використовується попередній локальний ключ підпису.

Один цільовий Android-тест пройшов: вулиці й номери будинків відображаються офлайн в обох темах. APK — 502 748 874 байти; підпис і ZIP-вирівнювання перевірені. Повний попередній набір онлайн / 3D та GPS фізичного телефона цим запуском не перевірялись.
