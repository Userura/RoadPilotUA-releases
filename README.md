## Поточна версія

# RoadPilotUA 0.1.7

Після «Почати рух» на екрані навігатора показуються області й райони, які перетинає вибраний маршрут. Області та райони поза маршрутом відсіюються, навіть якщо вони поруч із пристроєм або належать тій самій області. Геометричний індекс враховує короткі перетини, острови й отвори полігонів. Пройдені ділянки прибираються лише за придатним GPS-прогресом; при втраті GPS охоплення залишається консервативним.

Банер показує стан, зміни рівня та відбій окремих територій. Натискання відкриває повний список територій маршруту. Виїзд із району, перебудова маршруту й втрата мережі не оголошуються відбоєм. Дані старші трьох хвилин позначаються як невідомі. Тип «ракетна небезпека» застосовується лише за явним поточним типом загрози; червоний рівень сам по собі тип не підтверджує.

Фонову службу повітряних тривог вилучено. Повідомлення повітряної небезпеки в панель Android не надсилаються; старі повідомлення прибираються при оновленні. Перевірка прив'язана до відкритого екрана активної поїздки й призупиняється при згортанні застосунку. Сповіщення завантаження карт залишаються окремою функцією.

Джерело тривог — [Tryvoha.online](https://tryvoha.online/api), без токена, опитування приблизно раз на хвилину. Це довідкове джерело; офіційні сирени й повідомлення мають пріоритет. Без інтернету або в режимі «без інтернету» свіжий статус недоступний.

Номери будинків тепер починають відображатися з масштабу z15. Відновлено адресні підписи детальних регіональних та онлайн-карт: вбудований шар більше не видаляє їх. Для регіональних векторних даних підтримуються поля `addr_housenumber`, `housenumber` і `addr:housenumber`, у тому числі на контурах будівель.

Конкретну адресу **Миколаїв, Фонтанна вулиця, 73** перевірено окремо: у вихідному OSM-витягу номера біля цієї вулиці немає. До `verified-addresses.geojson` додано одну довідкову адресну точку за [публічною адресною сторінкою Візіком](https://maps.visicom.ua/i/ADR3K7ZJTTD7VWC4Q2), із зазначенням джерела та дати перевірки. Вона є позначкою карти й не змінює GPS-позицію пристрою.

Основний офлайн-архів із 1 700 067 записами OSM збережено. Відсутні в джерелах адреси не вигадуються; це не повний офіційний адресний реєстр України.

Версія 0.1.7, versionCode 19, попередній ключ підпису. 236 модульних тестів і 2 цільові Android-тести пройдено; підпис, ресурси APK та ZIP-вирівнювання перевірені. Android-тести підтвердили адресні підписи на z15 у Києві й Миколаєві в обох темах та екранні стани тривоги, явної ракетної небезпеки й відбою для маршруту. Для перевірки станів використано тестовий набір даних, який не входить до release APK. Повний попередній набір онлайн / 3D та GPS на фізичному телефоні не перевірялися повторно.


APK підписаний ключем RoadPilotUA. Контрольна сума також додається до релізу окремим файлом `SHA256SUMS.txt`.
